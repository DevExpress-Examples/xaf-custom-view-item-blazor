# XAF Blazor - Use a Custom View Item to Add a Button to a Detail View

This example shows how to add a custom component to a Detail View. We add a button to a Detail View and display a message when a user clicks the button.

For detailed instructions, refer to the following topic: [How to Add an Unbound Control (Button) to the Form Layout in an XAF View (with a Fully Custom ViewItem)](https://docs.devexpress.com/eXpressAppFramework/113653/ui-construction/view-items-and-property-editors/add-a-button-to-a-detail-view-using-custom-view-item).
